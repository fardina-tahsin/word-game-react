# Word Guess Game

A fun and interactive Word Guess Game built with React, featuring an animated teddy that reacts to wrong guesses instead of the traditional hangman.

<img width="1918" height="1010" alt="word game" src="https://github.com/user-attachments/assets/fdac3199-7235-409c-8742-183170080bf8" />


## Features

     Random word selection
    
     On-screen letter buttons (A–Z)
    
     Wrong guess tracking
    
     Animated teddy reacts to wrong guesses
    
     Win / Lose detection
    
     Restart game anytime
    
     Responsive design 
    
     Clean and modern UI


## Tech Stack

    React (Functional Components)
    
    Custom React Hooks
    
    CSS (Flexbox & Animations)
    
    JavaScript (ES6+)
